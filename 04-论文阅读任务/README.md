## 1. 小论文（会议 / 期刊论文）写作要点

### 1.1 结构骨架（IMRaD）

| 章节 | 要回答的问题 | 常见问题 |
|---|---|---|
| **Abstract** | 做了什么、怎么做的、结果多好 | 只写背景不写结果，没有量化数字 |
| **Introduction** | 问题为什么重要？已有工作差在哪？我们怎么做？ | 「故事线」断裂，缺少从痛点到方法的逻辑链 |
| **Related Work** | 前人做了什么，和他们比我们新在哪 | 变成文献罗列，没有「对比—定位」 |
| **Method** | 我们的方法怎么工作，为什么这样设计 | 只写公式不讲动机；符号前后不一致 |
| **Experiments** | 数据集、基线、指标、主结果、消融 | 缺 baseline、缺消融、缺显著性分析 |
| **Conclusion** | 结论与局限、未来工作 | 复述摘要，不提 limitations |

### 1.2 写作前的三件事

1. **一句话讲清贡献（One-sentence claim）**：如果不能用一句话说清「我比 SOTA 好在哪」，
   说明实验设计还没想清楚。建议先写 Introduction 的最后一段（贡献列表），再写正文。
2. **先图后文**：把主图（总框架图）、主表（结果表）先画出来，全文围绕它组织。
   审稿人通常 10 分钟内看：题目 → 摘要 → 图 1 → 主结果表 → 结论。
3. **确定目标会议/期刊的格式与篇幅**：不同会议的页数、模板、引用风格差异很大，
   提前用官方 LaTeX 模板写，避免后期大改。

### 1.3 各部分的写作要领

- **题目**：具体、可检索。避免「A Novel ...」这类空词；把方法和任务都体现出来。
- **摘要**（150–250 词）：背景 1 句 → 问题 1 句 → 方法 2–3 句 → 结果 2 句（**带数字**）→ 意义 1 句。
- **引言**：用「漏斗结构」——领域重要性 → 现有方法及其不足 → 本文思路 → 贡献列表（3 条左右）。
- **方法**：先给总览图与整体流程，再分小节展开；每个模块先讲**动机**再讲**公式**；
  公式里的每个符号都要在首次出现处定义，全文统一。
- **实验**：
  - 主表要给全 baseline（经典方法 + 近两年 SOTA），并注明是原文引用还是自己复现；
  - 消融实验要控制变量，一次只去掉一个模块；
  - 报告多次运行的平均值与标准差（或至少说明随机种子）；
  - 给出失败案例或局限性分析，反而能增加可信度。
- **图表**：图的字号不要小于正文；表格用三线表；图注要能独立读懂（self-contained）。
- **引用**：用 Zotero / EndNote 管理，避免漏引关键相关工作（这是最常见的拒稿理由之一）。

### 1.4 投稿前自检清单

- [ ] 摘要里有具体数字结果
- [ ] 贡献点在引言里明确列出，且与实验一一对应
- [ ] 所有 baseline 都可比（同数据集、同划分、同指标）
- [ ] 每个 claim 都能在正文找到实验支撑
- [ ] 符号表统一，公式可复现
- [ ] 图表在黑白打印下仍可区分
- [ ] 参考文献格式统一，无重复、无错误
- [ ] 英文表达经过润色（注意中式英语、时态：方法用一般现在时，实验操作用过去时）

### 1.5 时间安排建议

| 阶段 | 建议占比 |
|---|---|
| 实验与结果整理 | 50% |
| 写作初稿 | 20% |
| 反复修改与打磨 | 25% |
| 格式检查与投稿准备 | 5% |

**经验**：初稿写完先放一天再读，或者讲给同组的同学听——听不懂的地方就是要改的地方。

## 2. 大论文（学位论文）写作要点

### 2.1 与小论文的核心差别

| 维度 | 小论文 | 大论文 |
|---|---|---|
| 篇幅 | 8–12 页 | 60–120 页 |
| 结构 | 单点突破 | 多个工作构成一个**完整体系** |
| 创新要求 | 一个明确创新点 | 各章各有创新，且章与章之间有逻辑递进 |
| 叙述方式 | 紧凑，假设读者是同行 | 更完整，需要自洽的背景、术语定义与综述 |
| 审查重点 | 新颖性、实验充分性 | 系统性、工作量、逻辑闭环、格式规范 |

### 2.2 典型章节安排

1. **绪论**：研究背景与意义 → 国内外研究现状（综述）→ 存在的问题 → 本文研究内容与贡献 → 论文组织结构
2. **相关理论基础**：概念、定义、符号约定、预备知识
3. **第 3~N 章：具体工作**，每章结构统一为
   「引言 → 问题定义 → 方法 → 实验 → 本章小结」
4. **总结与展望**：全文工作总结 → 创新点归纳 → 不足与未来工作

### 2.3 关键原则

- **逻辑主线**：全文要有一条主线（例如「数据关联 → 质量保障 → 智能研判」），
  每章开头说明本章与主线的对应关系，章末说明向下一章的过渡。
- **避免重复**：基础理论只在前置章节讲一次，后续章节引用即可。
- **符号统一**：建立全文符号表，同一符号在不同章节含义必须一致。
- **工作量体现**：每章都要有完整的方法 + 实验闭环，并明确标注本章创新点。
- **附图规范**：总框架图放在绪论，各章有本章方法图；图、表、公式分别连续编号。

### 2.4 格式与规范（多数学校会严格审查）

- 页面设置、页边距、行距、字体、字号按学校模板（注意中英文混排的字体区分）；
- 标题编号层级统一（如 二、→（二）→2. →2.1→2.1.1）；
- 缩略词首次出现给全称；外来语中英文并列；
- 图表要在正文中被引用（「如图 2-1 所示」）；
- 参考文献著录格式统一（GB/T 7714 或学校指定）；
- **查重与学术规范**：直接引用必须标注，避免自我抄袭（已发表的小论文内容需说明并引用）。

### 2.5 写作节奏建议

- 不要把写作全部留到最后：**每完成一个工作就写好对应章节**（工作记忆最新鲜）；
- 先写「方法」和「实验」章，最后写「绪论」和「总结」；
- 定稿前至少通读 3 遍：第 1 遍看逻辑，第 2 遍看表述，第 3 遍只看格式与错别字。

## 4. 本次阅读的收获（自查）

1. 小论文的核心是「**一个清晰的创新点 + 充分可比的实验**」，其他部分都是为了支撑这两件事；
2. 大论文的核心是「**多个工作之间的逻辑关系**」，要有主线，不能是几篇小论文的简单拼盘；
3. 写作不是实验做完之后才开始的收尾工作，而是研究过程中的一部分：
   用「写作倒逼实验」——当你写不清贡献时，说明实验还没设计好。
