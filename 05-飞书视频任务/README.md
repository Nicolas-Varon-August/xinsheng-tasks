## 2. 飞书核心功能对照清单（看完请逐条打勾）

### 2.1 消息与沟通

- [ ] 单聊 / 群聊：发送文本、表情回复（Reaction）、@ 某人
- [ ] **消息引用回复**与**话题（Thread）**：把讨论收拢在一条消息下，避免刷屏
- [ ] 消息加急（应用内 / 短信 / 电话加急）、稍后处理、标记未读
- [ ] 消息翻译、语音转文字
- [ ] 群机器人（自定义机器人 Webhook、GitHub / 日历等官方机器人）
- [ ] 群公告、群置顶、群投票

### 2.2 云文档（Docs / Sheets / Slides）

- [ ] 新建文档 / 表格 / 幻灯片 / 思维笔记 / 多维表格
- [ ] **@ 提及人与文档**：`@人名` 直接通知，`@文档名` 建立双链
- [ ] 评论与「解决」评论、划词讨论
- [ ] 权限设置：仅指定人可编辑 / 可阅读，链接分享的开关，**外部分享**限制
- [ ] 版本历史与差异对比、文档内搜索
- [ ] 导入导出（Word / Excel / PDF / Markdown）

### 2.3 多维表格（Base）

- [ ] 表格视图 / 看板视图 / 甘特图 / 日历视图的切换
- [ ] 字段类型（人员、日期、单选多选、附件、公式、关联）
- [ ] 关联字段实现表与表之间的关联（类似数据库的外键）
- [ ] 自动化流程（当…则…）、按钮字段
- [ ] 仪表盘（统计图）

### 2.4 日历与会议

- [ ] 创建日程、邀请参会人、查看他人空闲时间
- [ ] 循环日程、日程提醒、把日程同步到手机系统日历
- [ ] **视频会议**：预约会议 / 即时会议、共享屏幕、录制（妙记）
- [ ] **妙记（Minutes）**：会议录音自动转文字、生成智能纪要、按发言人分段

### 2.5 任务与 OKR

- [ ] 任务：创建任务、指派负责人、设置截止时间与优先级、子任务
- [ ] 任务与文档 / 消息的关联
- [ ] OKR：目标（O）与关键结果（KR）的设置与对齐

### 2.6 效率技巧（视频里通常重点讲）

- [ ] **全局搜索**：`Ctrl/Cmd + K`，可以搜消息、文档、联系人
- [ ] **快捷指令 / 斜杠命令**：在消息框输入 `/` 调用功能
- [ ] 消息「稍后处理」+「未完成」组合当 TODO 用
- [ ] 用「我的空间」+ 文件夹整理文档，用「共享空间」做团队协作
- [ ] 把飞书日历与课程表 / 组会时间同步
- [ ] 移动端与桌面端消息同步、扫码登录

## 3. 与科研工作的结合（本组常用场景）

| 场景 | 飞书里的做法 |
|---|---|
| 组会安排 | 日历建循环日程 + 邀请全组 + 妙记录制 |
| 组会纪要 | 妙记生成文字稿 → 整理到云文档 → 在群里 @ 相关人 |
| 文献管理 | 多维表格建「文献库」：标题、作者、年份、链接、状态（待读/在读/已读） |
| 实验记录 | 云文档按日期建子页面，或用多维表格记录每次实验的配置与结果 |
| 周报 / 月报 | 云文档模板 + @ 导师；多维表格汇总全组进展 |
| 代码与文档 | 文档里 @ GitHub 仓库链接，群机器人推送 commit / PR 通知 |
